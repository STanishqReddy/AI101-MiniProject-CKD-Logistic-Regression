# Problem Statement

## Project Title
Chronic Kidney Disease Prediction Using Logistic Regression

## Problem
Chronic Kidney Disease (CKD) is a condition in which the kidneys gradually lose their ability to function properly. Early identification can help in timely medical evaluation and management.

This project aims to use patient health information, including medical indicators and laboratory test results, to build a machine learning model that can classify whether a patient is likely to have Chronic Kidney Disease.

## Project Objective
The objective is to develop a Logistic Regression classification model that predicts whether a patient has CKD or does not have CKD based on the available features in the dataset.

The project will also involve data preprocessing, model training, testing and evaluation using appropriate classification metrics.

## Dataset Information
- Dataset name: Chronic Kidney Disease Dataset
- Dataset source: Chronic_Kidney_Disease_data.csv (provided in the GitHub repository)
- Number of records: 1659
- Number of columns: 54
- Target column: Diagnosis


## Expected Outcome
Build an educational machine learning model that predicts the CKD target class using Logistic Regression.

The model's performance will be evaluated using suitable classification metrics such as accuracy, precision, recall and F1-score.
