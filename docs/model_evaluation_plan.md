# Model Evaluation Plan

## Project
Chronic Kidney Disease Prediction Using Logistic Regression

## Objective
Evaluate the performance of the Logistic Regression model.

## Evaluation Metrics

1. Accuracy
2. Precision
3. Recall
4. F1-score
5. Confusion Matrix
6. ROC-AUC
7. Precision-Recall Curve / PR-AUC

## Why Multiple Metrics?

The dataset may have an imbalanced target distribution.
Therefore, accuracy alone may not provide a complete
picture of model performance.

Precision, recall, F1-score and confusion matrix
will also be used.

## Planned Visualizations

- Confusion Matrix
- ROC Curve
- Precision-Recall Curve
